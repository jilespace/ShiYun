## 2. 现状分析（已逐条读码确认）

- **P2-1** `app/modules/auth.php:162-164`：CSRF 失败仅 `auth_render(...)`，无 `return`；`auth_render`（`auth.php:53-70`）内部 `render()`（`helpers.php:59-65`）**不 exit**，故失败后继续执行到 166 行起生成并写入 `password_resets`。

### P2-3　任务队列 CAS 抢占（`app/modules/tasks.php`）
`tasks_tick()` 的 `foreach ($queued as $task)`（L382 起）改为先抢占、再执行：
```php
    foreach ($queued as $task) {
        if (microtime(true) >= $deadline) {
            break;
        }
        // 原子抢占：仅当仍为 queued 时置为 running，成功者才执行，避免与
        // tasks_cron/页面加载并发时同一任务被处理两次
        $claimed = q_exec(
            "UPDATE transfer_tasks SET status = 'running', started_at = COALESCE(started_at, ?)
             WHERE id = ? AND status = 'queued'",
            [now(), (int) $task['id']]
        );
        if ($claimed === 0) {
            continue;
        }

        @ignore_user_abort(true);
        @set_time_limit(0);

        if ($task['kind'] === 'offline') { task_run_offline($task, $deadline); }
        elseif ($task['kind'] === 'bt') { task_run_bt($task); }
        elseif ($task['kind'] === 'push') { task_run_push($task); }
        elseif ($task['kind'] === 'purge') { task_run_purge($task); }
        else { q_update('transfer_tasks', ['status' => 'done', 'progress' => 100, 'finished_at' => now()], 'id = ?', [(int) $task['id']]); }
        $processed++;
    }
```
说明：各处 `task_run_*` 内部再次置 `running` 属幂等；offline 预算用尽/失败重试路径仍会回写 `queued`，语义不变。

```php
/** 批量取命中片段：用 LOCATE/SUBSTRING 只取窗口，避免把整段文本读进内存 */
function search_snippets_batch(array $nodeIds, string $q): array
{
    $nodeIds = array_values(array_filter(array_map('intval', $nodeIds), static fn (int $i): bool => $i > 0));
    if ($nodeIds === []) {
        return [];
    }
    $in = implode(',', array_fill(0, count($nodeIds), '?'));
    $needle = mb_strtolower($q);
    $out = [];
    foreach (q_all(
        "SELECT node_id,
                LOCATE(?, LOWER(text_content)) AS pos,
                SUBSTRING(text_content, GREATEST(1, LOCATE(?, LOWER(text_content)) - 40), 200) AS snip
         FROM file_index WHERE node_id IN ({$in})",
        [$needle, $needle, ...$nodeIds]
    ) as $r) {
        $pos = (int) $r['pos'];
        if ($pos <= 0 || (string) $r['snip'] === '') {
            continue;
        }
        $out[(int) $r['node_id']] = ($pos > 41 ? '…' : '') . (string) $r['snip'] . '…';
    }
    return $out;
}

/** 批量还原节点所在路径文本（一次取回全部祖先名） */
function search_paths_batch(int $userId, array $rows): array
{
    $rootId = user_root_id($userId);
    $rowIds = [];
    $need = [];
    foreach ($rows as $row) {
        $ids = array_values(array_filter(
            explode('/', trim((string) $row['path'], '/')),
            static fn (string $v): bool => $v !== ''
        ));
        array_pop($ids);   // 末段是自身，路径文本不含自身
        $rowIds[(int) $row['id']] = $ids;
        foreach ($ids as $i) {
            $need[(int) $i] = (int) $i;
        }
    }
    $names = [];
    if ($need !== []) {
        $in = implode(',', array_fill(0, count($need), '?'));
        foreach (q_all("SELECT id, name FROM nodes WHERE user_id = ? AND id IN ({$in})", [$userId, ...array_values($need)]) as $r) {
            $names[(int) $r['id']] = (string) $r['name'];
        }
    }
    $out = [];
    foreach ($rowIds as $nid => $ids) {
        $crumbs = [];
        foreach ($ids as $i) {
            $i = (int) $i;
            $crumbs[] = $i === $rootId ? '我的文件' : ($names[$i] ?? '…');
        }
        $out[$nid] = implode(' / ', $crumbs);
    }
    return $out;
}
```

```php
        'document' => ['label' => '文档', 'bytes' => 0, 'count' => 0],
        'archive'  => ['label' => '压缩包', 'bytes' => 0, 'count' => 0],
        'code'     => ['label' => '代码', 'bytes' => 0, 'count' => 0],
        'other'    => ['label' => '其他', 'bytes' => 0, 'count' => 0],
    ];
    $rows = q_all(
        "SELECT CASE
                   WHEN mime LIKE 'image/%' THEN 'image'
                   WHEN mime LIKE 'video/%' THEN 'video'
                   WHEN mime LIKE 'audio/%' THEN 'audio'
                   WHEN ext IN ('zip','rar','7z','tar','gz','bz2','xz','tgz') THEN 'archive'
                   WHEN ext IN ('js','mjs','ts','php','py','java','c','h','cpp','go','rs','rb','sh','sql','css','html','htm','json','yml','yaml','xml') THEN 'code'
                   WHEN ext IN ('doc','docx','xls','xlsx','ppt','pptx','pdf','txt','md','markdown','csv','tsv','odt','epub') THEN 'document'
                   ELSE 'other'
                 END AS bucket,
                 COUNT(*) AS cnt,
                 COALESCE(SUM(size), 0) AS bytes
         FROM nodes WHERE user_id = ? AND kind = 'file'
         GROUP BY bucket",
        [$userId]
    );
    foreach ($rows as $r) {
        $b = (string) $r['bucket'];
        if (isset($buckets[$b])) {
            $buckets[$b]['count'] = (int) $r['cnt'];
            $buckets[$b]['bytes'] = (int) $r['bytes'];
        }
    }
    return $buckets;
}
```
（保持原有语义：不按 `deleted_at` 过滤。）

### P2-13　打包：预取 hash + 总量上限（`app/lib/archive.php`）
- `app/config.example.php` 新增 `'max_pack' => 2 * 1024 ** 3,`（打包下载总量上限）。
- 新增预取助手：
  ```php
  /** 预取所选子树内所有文件的 blob_id→hash，避免逐文件查询 */
  function archive_prefetch_hashes(int $userId, array $nodes): array
  {
      $blobIds = [];
      $folderPaths = [];
      foreach ($nodes as $node) {
          if ($node['kind'] === 'file' && $node['blob_id'] !== null) {
              $blobIds[(int) $node['blob_id']] = (int) $node['blob_id'];
          } elseif ($node['kind'] === 'folder') {
              $folderPaths[] = (string) $node['path'] . '%';
          }
      }
      foreach ($folderPaths as $p) {
          foreach (q_all('SELECT blob_id FROM nodes WHERE user_id = ? AND kind = ? AND deleted_at IS NULL AND path LIKE ?',
                         [$userId, 'file', $p]) as $r) {
              if ($r['blob_id'] !== null) {
                  $blobIds[(int) $r['blob_id']] = (int) $r['blob_id'];
              }
          }
      }
      if ($blobIds === []) {
          return [];
      }
      $ids = array_values($blobIds);
      $in = implode(',', array_fill(0, count($ids), '?'));
      $map = [];
      foreach (q_all("SELECT id, hash FROM blobs WHERE id IN ({$in})", $ids) as $r) {
          $map[(int) $r['id']] = (string) $r['hash'];
      }
      return $map;
  }
  ```
- 改签名：`zip_add_folder(..., array &$used, array &$totalBytes, array $hashes)` 与
  `zip_add_file(ZipArchive $zip, array $node, string $entry, array &$used, int &$totalBytes, array $hashes)`；
  `zip_add_file` 用 `$hashes[(int)$node['blob_id']] ?? ''` 取代内部 `q_val`。
- `zip_stream_nodes()` 与 `compress_nodes()` 在开始打包前各调用一次
  `$hashes = archive_prefetch_hashes($userId, $nodes);` 并透传。
- 总量上限：`zip_add_file` 累加后若 `$totalBytes > (int) config('max_pack')` 抛 `RuntimeException('打包体积超过上限')`；
  `zip_stream_nodes()` 用 `try/catch` 包裹打包循环，捕获后 `@unlink($tmp)` 并返回 413。
