# 拾云 · P0+P1 修复实施计划

## 1. 摘要

| 编号 | 问题 | 修复文件 | 方式 |
|---|---|---|---|
| P0-1 | 找回密码未配邮件时明文回显重置链接（任意账号接管） | `app/modules/auth.php`、`app/config.example.php` | 新增配置 `reset_link_in_response`（默认 false），默认不回显、仅写日志 |

| P1-5 | 存储源可致 SSRF / 任意本地路径写入 | `storage_drivers.php`、`sources.php`、`tasks.php`、`views/sources.php` | 仅加非阻塞风险告警（用户已选） |

约束：不新增依赖/新表/新框架；除一个配置项外不加新配置。所有 PHP 改动保持 `declare(strict_types=1)` 与现有异常风格。

## 3. 具体改动

### P0-1 `app/modules/auth.php`
改 `auth_do_forgot()`（L158-L194）：保留反枚举的"中性回应"，只调整链接暴露。
- `$mailConfigured = function_exists('mail') && (bool) config('mail_enabled', false);`
- 若 `$mailConfigured` → 发信、`$resetLink = null;`（原逻辑）。
- 否则若 `config('reset_link_in_response', false)` 为真 → 保留 `$resetLink`（自部署显式开启才回显）。
- 否则（默认）→ `$resetLink = null;`，并 `error_log('[auth.forgot] reset link for ' . $email . ': ' . <原链接>)` 仅落日志。
- `$notice` 中性不变；未发信且未回显时可追加"（未配置邮件服务时请联系管理员）"，不区分账号是否存在。

`app/config.example.php`「安全」段新增（带注释）：
```php
// 仅本机/单人自部署可开启；多用户环境务必保持 false
'reset_link_in_response' => false,
```
`app/config.php` 不改：代码用 `config('reset_link_in_response', false)`，缺省即安全。`app/views/auth.php` 不改（仅当非 null 才渲染）。

### P0-2 补齐私密守卫（复用现有表达式）
- `preview.php`：`preview_text()`、`preview_office()` 在 `node_require`+kind 校验后加 `if (node_in_private($userId,$node) && !Auth::privateUnlocked()) json_fail('私密空间已锁定。',403,'private_locked');`
- `files.php`：`files_info()` 在 `node_require` 后同上（json_fail 403）。
- `download.php`：`download_zip()` 取到 `$nodes` 后遍历，任一命中守卫 → `http_response_code(403); exit('私密空间已锁定');`
- `api.php`：`api_route_list()`、`api_route_stat()`、`api_route_download()` 在各自 `node_require` 后加 json_fail 403；保持 `api_route_download()` 中已有 `node_in_private(` 早于 `blob_deliver(`。
- `versions.php`：`versions_list()` 加 json_fail 403；`versions_download()` 在计算 `$inPrivate` 前加**拒绝**守卫（用 `$version['node_id']`/`node_path` 构造 node 片段），再执行原 `blob_deliver` 判断。
- 范围外：`versions_restore/delete`（仅影响本人数据，不泄漏内容）。

### P0-3 `app/lib/nodes.php` `node_purge()`
在 `$ids` 就绪后、`DELETE` 之前插入：
```php
$versionRows = q_all("SELECT blob_id, size FROM node_versions WHERE node_id IN ({$in})", $ids);
foreach ($versionRows as $v) {
    blob_release((int) $v['blob_id']);
    $freedBytes += (int) $v['size'];
}
```
放于 `DELETE FROM node_versions`（L647）之前；`blob_release()` 依赖 `db.php` L164-L198 的 SAVEPOINT 嵌套，可在外层事务内调用；字节并入既有 `user_add_usage(-$freedBytes)`。

### P1-1 `app/modules/webdav.php` `webdav_auth()`
仅账号密码路径（不含 `sy_` 令牌路径）：
- `password_verify` 前：`if (login_locked($login, client_ip())) { header('WWW-Authenticate: Basic realm="拾云 WebDAV"'); http_response_code(429); exit('尝试次数过多，请稍后再试。'); }`
- 失败：`log_login($user !== null ? (int)$user['id'] : null, $login, 'fail', 'WebDAV 密码错误');`
- 成功：`log_login((int)$user['id'], $login, 'success', 'WebDAV');`
`login_locked()/log_login()` 已在 `app/auth.php` 且 bootstrap 已加载。

### P1-2 三处 XSS
- `assets/js/upload.js` L160：`'<span>' + escapeHtml(stateText) + '</span>'`
- `assets/js/viewer.js` L161-L166：新增 `const safeHref = (u) => /^(https?:|mailto:|\/|#|\.)/i.test(String(u).trim()) ? u : '#';`，L166 替换回调改用 `safeHref($2)` 作 href，保留 `target="_blank" rel="noopener noreferrer"`。
- `assets/js/console.js` L605-L606：对 `f.name` 与调色板颜色分别 `escapeHtml` 后再拼 `<option>`；L622 的 `escapeHtml(folderOpts)` 保留不动。

### P1-3 版本计入配额
- `app/lib/users.php` `user_recompute_usage()`（L155-L164）：用量 = `nodes(kind='file') SUM(size)` + `node_versions JOIN nodes SUM(v.size)`（同 user 维度）。
- `app/lib/versions.php`：`node_replace_content()` 末尾 L67 的增量改为 `user_recompute_usage($userId);`；`version_delete()`（L107-L122）与 `versions_prune()`（L124-L139）在删除+`blob_release()` 后补 `user_recompute_usage($userId);`。
- 调用方不改（`upload_complete`/`api_route_upload`/`webdav_put`/`version_restore`）；重复重算仅两条聚合查询，无副作用。

### P1-4 `assets/js/app.js`
- 点击处理器（L333-L341）：在 `if (!link.dataset.goto) return;` 后加 `if (!document.querySelector('[data-pane="' + link.dataset.goto + '"]')) return;`（目标 pane 不存在则不 `preventDefault`，按 href 整页跳转）。
- `activate(name, updateUrl)`（L288-L331）：增加第三参 `link`；L329 改为 `history.replaceState(null, '', link.href)`；调用处（L339）传 `link`。

### P1-5 非阻塞风险告警（不拦截）
- `app/lib/storage_drivers.php` 新增纯函数：
  - `host_risk_note(string $host): ?string`：host 为回环/私网/链路本地/云元数据（`127.*`、`localhost`、`10.*`、`192.168.*`、`172.16-31.*`、`169.254.*`、`::1`、`fc00::/fe80::`、`metadata.google.internal`）时返回警示，否则 null。仅字符串/IP 判断，不做 DNS 解析。
  - `source_risk_note(array $source): ?string`：sftp/ftp/s3 取 `config.host`→`host_risk_note`；local 取 `config.root`，`realpath` 不在 `BASE_PATH` 下则警示。
- `app/modules/sources.php`：`sources_test()`、`sources_create()`、`sources_update()` 的 `json_ok` 附带 `'warning' => source_risk_note($source)`。
- `app/views/sources.php`：`sources_list()` 为每个源计算 `riskNote` 放入 `$sources[$i]['riskNote']`，视图用现有 `.note` 样式渲染。
- `app/modules/tasks.php` `tasks_create()`：离线 URL 的 host 经 `host_risk_note()`，非空时 `json_ok` 带 `'warning'`（不阻断）。

## 4. 假设与决策
1. P0-1 用显式开关 `reset_link_in_response`，缺省 false → 线上 `config.php` 无需改动即安全默认。
2. P0-2 不新增封装函数，复用 `node_in_private(...) && !Auth::privateUnlocked()`，保持 `t9` 通过。
3. P1-1 仅对 WebDAV 账号密码路径限流；令牌路径不限流。复用 `login_logs`，不建新表。
4. P1-3 以"重算为准"消除漂移，不做增量对冲。
5. P1-5 只告警不拦截、不做 DNS 解析。
6. 范围仅 P0+P1；不触碰 `versions_restore/delete` 私密守卫（P2）与其余 P2/P3。
7. 保持现有异常风格（`json_fail` / `http_response_code`+exit）。
